# Ficha de Anamnese e Avaliação Inicial – Pilates

Aplicação web moderna e profissional desenvolvida para **Tássia - Educadora Física** ([@tassia.movimento](https://instagram.com/tassia.movimento)), especializada em prescrição clínica e avaliação biomecânica para Pilates.

---

## 📋 Funcionalidades Principais

- **Fluxo em 3 Etapas (Wizard & Tabs)**:
  1. **Dados Pessoais e Objetivos**: Cadastro completo do aluno, histórico de atividade física, experiência com Pilates e contato de emergência.
  2. **Saúde e Hábitos**: Patologias prévias (hipertensão, hérnia de disco, artrose, etc.), medicamentos de uso contínuo, sinais durante o esforço, hábitos de sono/estresse, prevenção de quedas para idosos e **Escala Visual Analógica de Dor (EVA de 0 a 10)** em repouso e movimento.
  3. **Avaliação Física e Planejamento**: Avaliação postural estática e dinâmica, padrão de marcha, teste sentar/levantar, tabela interativa com movimentos específicos do Pilates (Ponte, Roll-Up, Agachamento, Spine Twist, etc.), conduta inicial e termo de responsabilidade com assinaturas.

- **Exportação e Download de PDF Profissional**:
  - Geração automática com **`html2pdf.js`** com download nomeado como `Anamnese_[Nome_do_Aluno].pdf`.
  - Layout limpo diagramado para documentação clínica e impressão direta (A4).
  - Modo de Pré-visualização do Documento antes de salvar.

- **Persistência e Usabilidade**:
  - Salvamento automático de rascunhos em `localStorage`.
  - Botão de carga rápida de exemplo demonstrativo da aluna Mariana.

---

## 🚀 Como Rodar o Projeto Localmente

1. **Instalar dependências**:
```bash
npm install
```

2. **Iniciar servidor de desenvolvimento**:
```bash
npm run dev
```

3. **Gerar build de produção**:
```bash
npm run build
```
